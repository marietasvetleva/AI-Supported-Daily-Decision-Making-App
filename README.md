
# Ahead — AI-Powered Daily Decision Assistant

Ahead is an iOS application developed using Swift and SwiftUI that helps users make everyday decisions through AI-powered, context-aware recommendations.

The application combines real-time weather information, location data and personal preferences to generate personalised suggestions for daily activities and places to visit.

## Project Overview

Everyday decisions, such as choosing where to go or what activity to do, can become time-consuming when users need to consider multiple factors.

Existing applications often focus on individual factors, such as weather or navigation, requiring users to combine information themselves.

Ahead addresses this challenge by bringing contextual information together and using Gemini AI to generate relevant recommendations.

The goal is to reduce decision fatigue and help users make more informed decisions through a simple, personalised mobile experience.

## Key Features

### AI-Powered Recommendations
- Uses Gemini AI to generate context-aware recommendations.
- Considers available contextual information when suggesting activities and locations.
- Provides personalised suggestions to support everyday decisions.

### Live Weather Integration
- Integrates Apple's WeatherKit to retrieve weather information.
- Uses current weather conditions as contextual input for recommendations.
- Helps users choose activities suitable for the weather.

### Location-Based Recommendations
- Incorporates user location into the recommendation process.
- Generates suggestions relevant to the user's surroundings.
- Supports discovering activities and places based on location.

### User Preferences
- Allows users to configure personal preferences.
- Adapts recommendations to individual interests and decision-making styles.
- Creates a more personalised application experience.

### User Interface
- Developed using SwiftUI.
- Designed around a simple and intuitive recommendation experience.
- Includes screens for onboarding, preference selection and personalised recommendations.

## Application Architecture

Ahead integrates multiple services to generate context-aware recommendations.

The application combines:

1. **User Input:** Personal preferences and information provided by the user.
2. **Contextual Data:** Weather conditions and location information.
3. **AI Recommendation Service:** Gemini AI processes the available context to generate recommendations.
4. **User Interface:** SwiftUI presents the recommendations through the mobile application.

The project included research and documentation of the client-side and service-side architecture to support the integration of these components.

## Research & Design

Before development, user research was conducted to understand how environmental factors influence everyday decisions.

### User Research
- Conducted a survey to investigate users' decision-making habits.
- Identified weather, travel time, crowd levels, convenience and personal preferences as important factors.
- Analysed existing applications to identify opportunities for combining contextual information.

### UI/UX Design
- Created user flow diagrams and paper wireframes.
- Designed an interactive Figma prototype.
- Developed onboarding, preference selection and recommendation screens.
- Conducted user testing to evaluate usability and the recommendation concept.

The feedback highlighted the importance of providing understandable recommendations and greater transparency about how suggestions are generated.


## Testing & Evaluation

The application was evaluated through prototype testing and feedback collected during the Project Market.

Users responded positively to:

- Personalised recommendations.
- AI-powered suggestions.
- The application's simple interface.
- The overall visual design and user experience.

Feedback also identified areas for improvement, particularly route recommendations and map integration.

## Project Outcome

The project resulted in a functional iOS application that combines Gemini AI, live weather data, location information and user preferences to support everyday decision-making.

The implementation demonstrated how contextual information can be integrated into an AI-powered mobile application to generate personalised recommendations.

The project also provided practical experience in connecting external services, developing mobile interfaces and evaluating an application through user feedback.

## Future Improvements

Potential improvements include:

- **Route Recommendations:** Suggest suitable travel routes based on contextual information.
- **Map Integration:** Integrate Google Maps or another mapping service.
- **Gesture Interactions:** Explore device interactions such as shake gestures for quick recommendations.
- **Advanced Personalisation:** Improve recommendations using additional preferences and contextual factors.
- **Recommendation Transparency:** Provide clearer explanations of how suggestions are generated.
