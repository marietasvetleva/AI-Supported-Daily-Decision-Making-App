# AI-Supported Daily Decision Making

# Project Description

This project focuses on developing a context-aware mobile application that helps users make easier daily decisions regarding routes, locations and activities. The app combines environmental and contextual information such as weather conditions, traffic, crowd levels and user preferences to provide personalized recommendations and simplify everyday decision making.

The goal of the application is to reduce decision fatigue and improve convenience by helping users quickly determine the best options for their current situation.

# Features
- Context-aware recommendations
- Smart route suggestions
- Weather and traffic integration
- Personalised user preferences
- Nearby location recommendations
- Crowd-aware suggestions
- Daily activity support
- Simplified decision-making experience
